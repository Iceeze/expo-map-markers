# Карта и изображения

Учебное мобильное приложение на React Native, Expo и TypeScript. Пользователь добавляет маркеры на карту, открывает их координаты и прикрепляет фотографии из галереи телефона.

## Установка и запуск

1. Установите актуальную **LTS-версию Node.js** с [официального сайта](https://nodejs.org/en/download). Для используемого Expo SDK 57 нужна версия Node.js **не ниже 22.13**: [требования Expo](https://docs.expo.dev/versions/v57.0.0/). После установки заново откройте терминал.
2. Установите **Expo Go** на телефон Android или iPhone. Ссылки на приложение есть на [странице настройки Expo](https://docs.expo.dev/get-started/set-up-your-environment/). Версия Expo Go должна поддерживать SDK 57.
3. Откройте терминал в папке проекта и введите команды:

   ```powershell
   node --version
   npm --version
   npm install
   npm start
   ```

   `npm install` устанавливает зависимости, а `npm start` запускает сервер разработки и показывает QR-код.

Оставляйте терминал с сервером открытым во время работы. Для остановки нажмите `Ctrl+C`.

## Как пользоваться

1. Дождитесь карты. Начальная область — Екатеринбург; карту можно перемещать и масштабировать. Если карта пустая после восстановления интернета, нажмите **«Обновить карту»**.
2. Удерживайте палец на свободном месте карты, чтобы добавить маркер.
3. Нажмите на маркер. Откроется экран с его широтой, долготой и фотографиями.
4. Нажмите **«Добавить изображение»** и выберите одну фотографию из галереи. Для нескольких фотографий повторите действие. Отмена выбора ничего не меняет.
5. Для удаления нажмите **«Удалить изображение»** под нужной фотографией. Файл в галерее телефона остаётся на месте.
6. Нажмите **«Вернуться к карте»** или кнопку назад в заголовке. На Android также можно использовать системную кнопку назад.

У каждого маркера свой список фотографий. Пока приложение работает, переходы между экранами сохраняют добавленные данные.

## Как устроен проект

| Файл | Назначение |
| --- | --- |
| `app/index.tsx` | Главный экран с картой и переходом к выбранному маркеру. |
| `app/marker/[id].tsx` | Экран деталей. `[id]` означает, что в адресе передаётся номер конкретного маркера. Здесь открывается галерея и добавляются фотографии. |
| `app/_layout.tsx` | Настраивает навигацию между экранами и общий доступ к маркерам. |
| `app/+not-found.tsx` | Показывает сообщение, если открыт неизвестный адрес экрана. |
| `components/Map.tsx` | Отображает карту и маркеры, обрабатывает долгое нажатие и состояние загрузки. |
| `components/MapErrorBoundary.tsx` | Показывает запасной экран при ошибке отрисовки карты в React. |
| `components/ImageList.tsx` | Показывает список фотографий и кнопки удаления. |
| `context/MarkersContext.tsx` | Хранит маркеры и функции добавления маркеров, добавления и удаления фотографий. |
| `types.ts` | Описывает форму координат, маркера, фотографии и параметров перехода. |
| `app.json` | Настройки Expo: название приложения, платформы и подключённые плагины. |
| `package.json` | Зависимости и команды запуска проекта. |
| `tsconfig.json` | Настройки проверки TypeScript. |

**Context** — встроенный механизм React для общих данных. Здесь оба экрана используют один список маркеров через `useMarkers()`. Список хранится в `useState` внутри `MarkersProvider`, который оборачивает приложение в `_layout.tsx`. Поэтому не нужно передавать весь список через параметры навигации: в адрес передаётся только `id`.

Для карты используется `react-native-maps`, для галереи — `expo-image-picker`, для переходов между файлами экранов — `expo-router`. Версии зависимостей подобраны под Expo SDK, чтобы библиотеки были совместимы.

## Ошибки и ограничения

- Данные хранятся **только в памяти**. После полного перезапуска или полной перезагрузки проекта маркеры и привязки фотографий исчезнут. Постоянное сохранение не входит в эту реализацию.
- Приложение рассчитано на **Android и iOS через Expo Go**. Веб-версия не предусмотрена. Для этой проверки не требуются Android Studio, Xcode или собственный ключ Google Maps: [карты в Expo Go](https://docs.expo.dev/versions/latest/sdk/map-view/).
- Карта загружает изображения местности из сети. Без интернета часть карты может оставаться пустой; уже загруженные участки иногда доступны из кеша устройства.
- Если карта не сообщает о готовности за 20 секунд, появляется сообщение с кнопкой **«Повторить»**. На Android таймер ожидает событие `onMapLoaded`, на iOS — инициализацию нативного компонента через `onMapReady`. На iOS это не гарантирует загрузку участков карты из сети. При пустой карте восстановите интернет и нажмите **«Обновить карту»**.
- `MapErrorBoundary` перехватывает ошибки отрисовки React. Он не может перехватить все сетевые ошибки карт или сбой самого нативного приложения. У библиотеки карт нет универсального события для каждой ошибки загрузки участков, поэтому таймер — простая подсказка при долгом ожидании, а не точная диагностика сети.
- Ошибки открытия галереи и получения изображения показываются сообщением. Если выбранная фотография стала недоступной, в списке появляется пояснение; её можно удалить и выбрать заново.
- Неверный или отсутствующий `id` маркера открывает экран **«Маркер не найден»** с возвратом к карте. Синхронные ошибки вызовов навигации обрабатываются сообщениями.

## Проверки

В папке проекта можно выполнить:

```powershell
npm run typecheck
npx expo install --check
npx expo-doctor
```

Первая команда проверяет TypeScript, вторая — соответствие зависимостей версии Expo, третья — конфигурацию проекта и совместимость библиотек. Эти проверки не заменяют запуск на телефоне.
